FREE HOSTING WITH GITHUB PAGES:
1. Sign in or create an account at https://github.com/
2. Create a PUBLIC repository named YOUR-USERNAME.github.io (replace with your username).
3. Upload index.html, style.css, robots.txt, sitemap.xml, and this README to the repository root.
4. Open Settings -> Pages.
5. Select deployment from a branch, choose main and /(root), then save.
6. Wait for deployment. Your address will be https://YOUR-USERNAME.github.io/
